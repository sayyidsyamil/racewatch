# 🏁 RaceWatch AI

> **RaceWatch AI** is your instant robot race judge! Upload your race video, get AI-powered scoring, and see your team on the leaderboard. Built for MYRC25. 🚗🤖🏆

**🌟 Try RaceWatch AI:**
- Upload your robot race video (Sekolah Rendah or Menengah)
- Choose Gemini Flash (free) or Pro (paid, higher quality)
- Get instant, editable AI evaluation and JSON output
- Save your result and see your team on the live leaderboard!

## Features
- 📹 Video upload & instant AI judging
- 🏫 Sekolah Rendah & Sekolah Menengah categories
- 🤖 Gemini Flash (free) & Pro (paid) model support
- 📝 Editable AI results, JSON output
- 🏆 Live leaderboard, sorted by time
- 📱 Mobile responsive, beautiful, and fun UI
- 🚨 User-friendly error handling

## Quick Start
1. **Clone the repo:**
   ```sh
   git clone https://github.com/sayyidsyamil/racewatch.git
   cd racewatch
   ```
2. **Install dependencies:**
   ```sh
   npm install
   ```
3. **Configure MongoDB:**
   - Copy `.env.local.example` to `.env.local` and set your MongoDB URI:
     ```env
     MONGODB_URI=mongodb+srv://<user>:<pass>@cluster.mongodb.net/racewatch?retryWrites=true&w=majority
     ```
4. **Run the app:**
   ```sh
   npm run dev
   ```
5. **Get your Gemini API key:**
   - [Gemini API Key Portal](https://aistudio.google.com/app/apikey)
   - Paste your key in the app UI
